# Design Direction

The practice view is a calm, dark rehearsal desk rather than a dense digital-audio workstation. Warm amber marks musical focus, mint indicates healthy synchronization, and restrained typography keeps the waveform and rhythmic pulse dominant. Controls remain keyboard reachable with visible focus; state is never communicated by color alone. Layout is desktop-first and collapses to a single column at tablet width. Reduced-motion preferences remove nonessential transitions.
